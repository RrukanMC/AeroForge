# 🛩️ AeroForge

AeroForge is a game about delivering packages and upgrading your own plane. Multiplayer, a dynamic weather system - all in one HTML file. 

## Features
- Realistic flight physics
- Dynamic weather system (clear/rain/fog)
- Day/night cycle with real-time sync
- Fuel system & retractable landing gear
- 5 upgrade levels
- Multiplayer via Firebase
- Photo Mode with screenshots
- Cinematic camera
- Customizable settings

## Play
Open `index.html` in your browser to play!

## Sounds & Fonts
Add your own `.mp3` files to `sounds/` and a `.ttf` font to `fonts/`
